## ▶️ Usage

### How to inspect and validate

1. Open the PBIX file in Power BI Desktop.
2. Check the data source, connection status, model tables, and refresh date.
3. Identify the transaction grain, date range, and currency.
4. Read each measure's DAX expression and confirm its filter context.
5. Reconcile headline metrics with the underlying data where accessible.
6. Export an aggregate results table and add real dashboard screenshots.

## 🧩 Challenges and Solutions

| Challenge | Solution |
|---|---|
| Dashboard measures can be misunderstood without definitions | Document formula, units, filters, and denominator for each KPI. |
| Source data may not be available outside the PBIX | Record the source, schema, refresh date, and validation approach. |
| Screenshots can be mistaken for reproducible evidence | Capture real report pages and reconcile headline values against data. |

## ⚠️ Limitations

### Limitations

- Dataset provenance, refresh status, schema, and license need documentation.
- Confirm whether measures exclude returns/cancellations and use a consistent currency.
- Geographic sales differences alone do not justify market expansion without cost, delivery, and competitive context.
