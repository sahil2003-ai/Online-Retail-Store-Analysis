# Online Retail Store Analysis Dashboard

A Power BI business-intelligence project designed to explore retail revenue trends, customer value, and country-level performance.

## Repository contents

| File | Purpose |
|---|---|
| `Online Retail Store Analysis Dashboard.pbix` | Power BI report |
| `README.md` | Project documentation |

## Analysis scope

The documented dashboard scope includes:
- Monthly revenue trends.
- Country-level comparisons by revenue and quantity.
- High-revenue customer comparisons.
- Geographic demand patterns to support further investigation.

These describe the intended questions, not independently verified findings.

## Technology

- Microsoft Power BI Desktop
- Power Query and DAX only where present in the PBIX model

## How to inspect and validate

1. Open the PBIX file in Power BI Desktop.
2. Check the data source, connection status, model tables, and refresh date.
3. Identify the transaction grain, date range, and currency.
4. Read each measure's DAX expression and confirm its filter context.
5. Reconcile headline metrics with the underlying data where accessible.
6. Export an aggregate results table and add real dashboard screenshots.

## Results and metric status

The repository contains the PBIX file but no source CSV, SQL script, notebook, exported summary, or screenshots in the current file inventory. The underlying data row count, revenue totals, top customers, and country rankings could not be independently recalculated from the repository contents available to this review. No numeric outcomes are invented here.

## Limitations

- Dataset provenance, refresh status, schema, and license need documentation.
- Confirm whether measures exclude returns/cancellations and use a consistent currency.
- Geographic sales differences alone do not justify market expansion without cost, delivery, and competitive context.
