## Project Overview
This report is designed to support exploration of retail performance, including revenue trends, customer contribution, and geographic differences.

## Business Questions
- How does retail revenue vary over time?
- Which customers contribute most to sales?
- Which countries or markets contribute most to recorded revenue?
- Are the report measures and filters consistent with the underlying source data?

## Dashboard Scope
The Power BI report is the main deliverable in this repository. Its underlying source dataset and exported measure definitions are not included in the current repository file inventory.

## Data and Metrics
The source row count, currency, date coverage, customer ranking, and country-level revenue totals could not be recalculated from the repository contents available for this review. No numerical business outcomes are invented here.

When documenting results, include the source-data name and date range, row count after cleaning, currency treatment, definitions for revenue and customer value, and validated country/customer summaries.

## Technology Stack
- **Power BI Desktop:** dashboard and interactive visual analysis.
- **Power Query / DAX:** inspect the transformations and measures saved in the report.

## Open the Report
1. Download or clone the repository.
2. Open `Online Retail Store Analysis Dashboard.pbix` in Power BI Desktop.
3. If prompted, reconnect the report to the original data source.
4. Refresh the model and validate the measures before relying on the displayed totals.

## Interpretation Notes
Country and customer rankings are descriptive, not proof of profitability or market opportunity. Check refunds/returns, cancelled transactions, currency, duplicate invoices, and date filters before comparing results.
